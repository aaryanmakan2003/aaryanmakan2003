# GLMS Logistics Platform

[Back to portfolio](../README.md)

A logistics coursework application with separate MVC and Web API layers for clients, contracts and service requests.

## Context and contribution

University logistics prototype. Coursework, starter material and other contributors retain their respective rights. This is not presented as a production service.

## Engineering focus

- Client and contract workflows with date validation and status transitions.
- Service requests linked to contracts, with rules for expired and on-hold contracts.
- DTO, service and repository layers in a separate API project.

Hosting controls remain in development. No operational documents or production data are shown.
