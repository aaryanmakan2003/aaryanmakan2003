# Project 12 After Dark

[Back to portfolio](../README.md)

A side-on drag-racing development build with fixed-step simulation, vehicle-specific driving and a local garage.

## Problem and approach

A racing prototype needs consistent simulation timing and responsive controls across changing frame rates.

## Technologies

TypeScript · React · Phaser 3 · Vite · Web Audio · Node test runner

## Context and contribution

Personal development project exploring fixed-step drag racing. The illustration is an abstract portfolio motif, not an in-game screenshot.

## Engineering focus

- Five playable choices with manual, automatic and CVT behaviour; additional garage entries remain planned.
- Burnout, launch reaction, traction, timed distance crossings and per-car records.
- Keyboard and pointer throttle controls with pause, restart and focus-loss handling.

## Demonstrated functionality

Earlier preparation passed 34 simulation checks and exercised garage, start, tyre warm-up and pause interactions locally. These results describe the prepared local version and were not rerun for this documentation update.
