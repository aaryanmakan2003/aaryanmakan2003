# University Engineering

[Back to portfolio](../README.md)

University development has given me practice moving between algorithms, backend services and integrated interfaces. These projects show different parts of that progression, rather than a single umbrella application.

## From data structures to connected systems

In **PROG7312**, [Smart-X](smart-x-iot-console.md) brings AVL-indexed history, priority ingestion and graph routing into a simulated IoT console. The engineering challenge is making the algorithms remain correct when telemetry arrives concurrently and routes change.

## From APIs to full-stack collaboration

In **INSY7314**, [Photostore](photostore-api.md) explores authenticated photo operations and the boundary between a database update and external image storage. [HustleHub+](hustlehub-plus.md) extends the learning into a collaborative React and Express marketplace with roles and booking flows. Its source documentation credits my frontend, rate-limiting and integration work; detailed component attribution remains under review.

## Layered application development

[GLMS](glms-logistics-platform.md), a university logistics project, separates ASP.NET MVC, API services and persistence. Its development scope includes logistics workflows and controlled PDF access. Tests cover service behaviour and document access using isolated fixtures; a complete SQL-backed deployment has not been demonstrated.

## Testing and integration

The prepared work includes algorithm checks, HTTP tests and browser interaction checks. These provide concrete feedback on concurrent ingestion, request validation, access control and recovery. Preparation also includes later verification work, so its test totals should not be treated as original assessment results or individual authorship metrics.

Cloud integration appears in Photostore's Cloudinary adapter. Its demonstrated tests substitute storage, so live cloud behaviour remains a separate verification step. React Native and Firebase are part of my broader skills; the cleared portfolio evidence does not currently support an additional mobile coursework case study here.
