# Campus Crisis Agent

[Back to portfolio](../README.md)

A hackathon prototype that correlates sequential incident reports, records uncertainty and replays how each decision evolved.

## Problem and approach

Repeated incident reports can conflict or describe the same event. A replay helps explain how a decision developed.

## Technologies

TypeScript · React · Vite · CSV processing · Optional Groq · Vitest

## Context and contribution

Team prototype. I contributed to its development; an exact individual contribution breakdown is still being confirmed. The demo uses fictional reports.

## Engineering focus

- Deterministic correlation across new, duplicate, corroborating, conflicting and resolved reports.
- Incident state, severity and action history with duplicate-dispatch prevention.
- A replay dashboard for inspecting evidence and recorded decisions.

## Demonstrated functionality

Earlier preparation passed ten tests and replayed six fictional reports without a live language-model request. These results describe the prepared local version and were not rerun for this documentation update.

## Development status

A recorded decision-replay prototype, not a live campus monitoring or emergency-dispatch system.
